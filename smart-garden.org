* Project Overview
ESP32-powered smart garden system using IoT sensors and solar
power. Monitors soil moisture, light, temperature, and humidity using
AIoT principles.

* Design
** Cluster design
   - *ESP8266 Sensors for cluster (Nodes)*
     - 1 Light sensor (BH1750)
     - 4 Soil Moisture Sensors
     - 1 Air Temperature and Humidity Sensor (SHT31)
     * 1 NPK Sensor for cluster (See if I can find one under $50.00 or
       if it is possible to make one.)
     - All have simple authenticated send/receive through MQTT protocol.
       - receive: report on sensor(s)
       - send: data from sensor(s)
       - only allowed communication with Assigned Hub (ESP32)
   - *Automatable devices (Automata)*
     - Water distribution units
     - Light distribution units
     * Nutrient distribution units (How to turn compost into a liquid?)
     - All have simple authenticated send/receive through MQTT protocol.
       - receive: start/stop/status
       - send: status
   - *ESP32 Hubs for clusters (Hub)*
     - Minor Management
       - Ex. If all soil sensors are indicating dry soil, start
         watering system if the Linux system is okay with it.
     - Communicates with Nodes and Automata
       - Sends and receives requests and responses by MQTT protocol to Nodes.
       - Nodes can only communicate with assigned Hub.
     - Communicates with Linux System through2 authenticated protocols
   - *Linux System (Base System)*
     - Monitors System.
     - Runs AI to make predictive analysis for healthy system.
       - Monitors Local Weather predictions to determine needs of
         garden.
         - Is it going to need water soon?
         - Is there going to be enough light?
         - Have the tomatoes had enough hardship to bloom?
         - Is a tornado going to destroy everything?
         - Is it going to be too hot/cold for the plants?

* Wiring Notes
- SHT31 → I²C (SDA=GPIO21, SCL=GPIO22)
- BH1750 → I²C (shared)
- Soil Moisture → Analog pin (e.g., GPIO34)
- MT3608 output → 5V into ESP32 VIN
